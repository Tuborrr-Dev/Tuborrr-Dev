## About

Hi, I'm **Israel Adetubo** ; a Backend developer who likes building things that move data reliably and fast. Most of my work sits at the intersection of automation, APIs and now AI: from Selenium pipelines that cut hours of manual reporting down to minutes, to **Pitchline**, a real time win probability terminal that turns a live football data stream into a Wall Street styled chart with AI-powered commentary.

I care about systems holding up under real conditions; sane schema design, resilient error handling and code that still makes sense six months later. I'm currently expanding into JavaScript/Node.js and transitioning toward Machine Learning engineering.

## Notable Projects

- **[Pitchline](https://github.com/Tuborrr-Dev/pitchline)**
  <sub>Real time AI football commentary told in the language of financial markets, win probability terminal built for the TxLINE World Cup Hackathon. Owned the FastAPI annotation microservice: rulebased + LLM(Groq Llama 3.3 70B) match narration over a live SSE feed, backed by PostgreSQL and Redis.</sub>

- **[LSA Booking Platform](https://github.com/Tuborrr-Dev/HabotConnect-LSA))**
  <sub>Flask REST API connecting parents with Learning Support Assistants. Multi role JWT authentication, schema validated endpoints, Razorpay style payment webhooks with HMAC verification and idempotent event processing, plus compound indexing to eliminate N+1 queries.</sub>

- **[Weather API Wrapper](https://github.com/Tuborrr-Dev/Weather-API-Wrapper)**
  <sub>FastAPI service wrapping OpenWeatherMap with Pydantic validated, typed endpoints and a Redis in memory caching layer to cut redundant upstream calls.</sub>

- **[Google Search Titles Scraper](https://github.com/Tuborrr-Dev/Google-Search-Titles-Scraper)**
  <sub>Selenium automation that drives dynamic search queries, parses unstructured DOM results and structures the output into Excel for auditing.</sub>

- **[Web Scraper & Crawler](https://github.com/Tuborrr-Dev/Web-Scraper-and-Web-Crawer)**
  <sub>Multipage crawler across dynamic pagination systems using Selenium, BeautifulSoup, and Pandas, with error handling for timeouts and missing elements.</sub>
